Hỗ trợ

AIGym Code giúp dev học và dùng Claude Code: tin chính thức mỗi ngày, Radar các repo skill, plugin và MCP server, tra cứu lệnh và cấu hình, bài học theo cấp.

Liên hệ

Báo lỗi hoặc góp ý: mở một issue tại GitHub Issues. Vui lòng ghi phiên bản app (xem ở tab Hồ sơ) và thiết bị bạn dùng.

Câu hỏi thường gặp

Khôi phục gói Trọn đời trên máy mới? Mở tab Hồ sơ, bấm “Khôi phục giao dịch mua” khi đăng nhập cùng Apple ID.

Dữ liệu cập nhật khi nào? Tin chính thức khoảng 3 giờ một lần; số sao của Radar mỗi đêm. Khi không có mạng, app dùng bản đã lưu và ghi rõ thời điểm.

Một repo trong Radar bị xếp sai nhóm? Hãy báo qua GitHub Issues kèm tên repo.

Quyền riêng tư? App không thu thập dữ liệu nào. Xem chính sách quyền riêng tư.

Support

AIGym Code helps developers learn and use Claude Code: official news every day, a Radar of skill, plugin and MCP server repos, a reference for commands and settings, and lessons by level.

Contact

Report a bug or send feedback by opening an issue on GitHub Issues. Please include the app version (shown in the Profile tab) and your device.

FAQ

Restore Lifetime on a new device? Open the Profile tab and tap “Restore Purchases” while signed in with the same Apple ID.

How often is data updated? Official news about every 3 hours; Radar star counts every night. Offline, the app shows the saved copy and says how old it is.

A repo is in the wrong Radar category? Report it on GitHub Issues with the repo name.

Privacy? The app collects no data. See the privacy policy.
